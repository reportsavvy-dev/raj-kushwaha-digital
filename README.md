## Portfolio

The repository includes `RajKumar Digital Marketing Portfolio.pdf` along with detailed client work and case-study pages inside the website.

## Local development

Requirements: Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Production validation:

```bash
npm run build
npm test
```
